# 3D models

Put `.glb`, `.gltf`, `.3mf`, and `.blend` files in this folder.

They are part of the git repo, so a push to GitHub stores them and a deploy can serve them from `/models/your-file.glb`.

Keep files under about 80 MB each. Large binaries work better with [Git LFS](https://git-lfs.com) later if the repo gets heavy.
